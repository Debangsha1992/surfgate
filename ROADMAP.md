# Roadmap

SurfGate's roadmap invites contributors to experiment with browser runtime routing. It describes research directions, not delivery dates or commitments.

## Current Developer Preview

The planned `v0.1.0` preview contains provider-neutral sessions, deterministic routing, Kitesurf and Chromium adapters, authenticated CDP relay, managed extract/screenshot/PDF tasks, durable state, private artifacts, security controls, observability, and provider conformance tests.

## Near-term

- Improve fresh-machine setup and examples
- Publish reproducible provider compatibility and routing benchmarks
- Strengthen raw-CDP network controls and deployment guidance
- Expand client compatibility testing
- Improve task output, artifact lifecycle, and reconciliation ergonomics

## Research / Experimental

- Additional browser runtimes
- Adaptive strategies that remain reproducible and explainable
- Provider health, latency, capacity, and cost signals
- Local single-user mode
- Developer CLI
- Additional CDP client compatibility

## Explicitly Out of Scope

- CAPTCHA bypass
- Browser fingerprint evasion
- Stealth or anti-bot circumvention
- Proxy rotation intended to evade access controls

Propose ideas through GitHub issues, including the use case, security impact, and how the change preserves provider-neutral boundaries.
