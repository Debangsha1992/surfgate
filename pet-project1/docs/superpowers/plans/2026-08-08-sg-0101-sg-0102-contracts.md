# SG-0101 and SG-0102 Contracts Implementation Plan

> **For Codex:** Follow this plan with test-driven development and stop before SG-0103.

**Goal:** Add framework-independent, runtime-validated SurfGate ID, public error, and browser capability contracts.

**Architecture:** `packages/contracts` is the single schema source for these public boundary types. Zod schemas validate runtime data and infer TypeScript types, while a small pure capability helper implements only hard-requirement eligibility semantics—never routing or scoring.

**Tech Stack:** TypeScript, Zod 4, Vitest, pnpm workspaces, Turbo.
