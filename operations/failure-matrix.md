# Dependency failure matrix

| Failure                      | API readiness / behavior                                                                                   | Relay readiness / behavior                                     | Worker readiness / behavior                             | Recovery                                                            |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- | ------------------------------------------------------- | ------------------------------------------------------------------- |
| PostgreSQL down/incompatible | Not ready; durable/auth/session/task operations return sanitized dependency errors                         | Not ready; new authorization fails closed                      | Not ready; no claims                                    | Restore DB/schema, verify migration ledger and reconciliation       |
| Redis down                   | Not ready; rate-limited/session-create paths fail closed                                                   | Not ready; new upgrades and revocation consistency fail closed | Unaffected unless future worker coordination uses Redis | Restore Redis; verify ownership, revocation, and quota behavior     |
| Object storage down          | API can serve sessions; artifact access fails stably                                                       | Unaffected                                                     | Not ready; no new artifact-producing work               | Restore private store; reconcile metadata/objects                   |
| Kitesurf down                | API remains live; routing rejects/penalizes it and may select Chromium                                     | Existing Kitesurf upstream may close; no active migration      | Kitesurf tasks fail/retry within task policy            | Restore provider; verify health and allocation                      |
| Chromium down                | Symmetric to Kitesurf                                                                                      | Existing Chromium upstream may close                           | Chromium tasks fail/retry within policy                 | Restore provider                                                    |
| Both providers down          | API live/ready for non-allocation operations; session creation returns stable no-compatible/provider error | Existing connections bounded by upstream state                 | Provider-backed work retries/fails boundedly            | Restore at least one provider; reconcile uncertain sessions         |
| Telemetry exporter down      | Serving unchanged; bounded queue/export timeout                                                            | Serving unchanged                                              | Serving unchanged                                       | Restore collector and verify export; telemetry never replaces audit |

Readiness is for new work; liveness is not coupled to downstream health. Raw diagnostics, connection strings, tokens, provider URLs, and topology never appear in public health responses.
